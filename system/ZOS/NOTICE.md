# Происхождение и лицензия

ZOS 0.1.0 — экспериментальный форк MineOS для мода OpenComputers (Minecraft).
Основа: архив MineOS-master.zip, предоставленный пользователем. Это не новая
операционная система для x86/UEFI и не Linux/Xfce.

Все исходные библиотеки, приложения, ресурсы и исходный LICENSE сохранены.
Изменены OS.lua и Libraries/System.lua; добавлены оболочка ZOSShell, ZOSPackages,
ZOS EFI, тема ZOS Luna, два статичных procedural-фона и установщик.

и условие разрешения содержат нестандартную непристойную вставку. Она сохранена

её юридически корректной. Перед публичным распространением выясните условия
у правообладателей либо замените основу на официальный архив с проверенной лицензией.
Изменённый исходный архив нельзя честно обозначать просто «MIT».

Новые файлы ZOS, не содержащие скопированного кода, доступны по MIT (LICENSE-ZOS).

Названия Windows XP и Xfce используются только для описания визуального направления.
Не включены оригинальные изображения Bliss, логотипы, шрифты или код Microsoft/Xfce.
ZOS EFI — название Lua-прошивки EEPROM, не реализация стандарта UEFI.
