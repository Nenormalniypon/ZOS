# Установка ZOS с официальными приложениями MineOS

Это небольшое обновление источников загрузки. Загрузите содержимое архива
в корень Nenormalniypon/ZOS, ветку main, с заменой совпадающих файлов.
Существующие папки удалять не нужно. Все файлы обновления текстовые.

Стандартные приложения, исходные библиотеки, изображения, языковые пакеты
и обои скачиваются с https://github.com/IgorTimofeev/MineOS .
Закреплена ревизия fb6c529e4d16198ad37dcc538ada99754294a456, проверенная
на побайтовое совпадение с файлами, ожидаемыми установщиком.

Из Nenormalniypon/ZOS скачиваются только изменённые/новые файлы ZOS:
оболочка, EFI, тема, собственные обои, локальный менеджер пакетов,
установщик и исправленные языковые файлы. Бинарная иконка нового менеджера
берётся с официального GitHub как копия иконки App Market.

Загрузка всего исходного Applications/ в ваш GitHub больше не требуется.
Ранее загруженные файлы приложений можно оставить: новый загрузчик их не использует,
кроме собственных файлов ZOS и явно изменённых модулей из этого обновления.

После публикации файлов выполните в OpenOS:

wget -f https://raw.githubusercontent.com/Nenormalniypon/ZOS/main/Installer/pastebin.lua /tmp/zos.lua
/tmp/zos.lua

Не запускайте старую копию /tmp/zos.lua без повторного wget.
Старые каталоги загрузки сохраняются, новая попытка получает свободное имя.
Нужны Internet Card, достаточно места на диске OpenOS и отдельный пустой HDD.
Это всё ещё alpha: тесты на модели компонентов пройдены, запуск в Minecraft
и доступность внешнего API App Market не подтверждены.

Главные изменения: Installer/pastebin.lua выбирает официальный источник по полю
source="mineos"; Installer/Manifest.lua закрепляет commit и перечисляет исключения ZOS.
Не заменяйте manifest старой версией. Для его пересборки обновлены tools/build_manifest.py
и tools/MineOS-source.json. Контрольные суммы относятся к установленным исходным байтам.
