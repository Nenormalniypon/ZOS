# Формат ZPK1

Байтовый контейнер, без Lua-manifest и без сжатия. Заголовки UTF-8/ASCII, разделитель LF.

1. `ZPK1\n`
2. ASCII-имя приложения без `.app`, затем `\n`. Разрешены буквы, цифры, пробел, `_`, `-`.
   Длина 1–48 символов.
3. Количество файлов десятичным числом и `\n`, от 1 до 256.
4. Для каждого файла: относительный путь и `\n`; длина в байтах и `\n`; ровно N байт.
   Следующий путь идёт сразу после данных, без дополнительного разделителя.
5. После последнего файла — EOF. Обязателен `Main.lua` в корне.

Не более 1 MiB на файл и 4 MiB суммарно. Результат: `/Applications/<имя>.app/`.
Существующее приложение не заменяется. Нет зависимостей, подписей и автообновления.
Данные читаются блоками по 4096 байт; полного распакованного пакета в RAM нет.
Имя пакета — не отображаемое локализованное имя и не имя файла-архива.
